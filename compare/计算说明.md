# 计算逻辑说明

配套脚本：`回测计算.py`（Python 3.7+，**只用标准库**，不需要 pandas / numpy / openpyxl）

```bash
python 回测计算.py                  # 默认读桌面 数据底稿.xlsx
python 回测计算.py 其他底稿.xlsx     # 或指定路径
```

输出：控制台打印四张表（全区间指标、年度分段、相关系数、回撤校验），并写出 `回测结果.csv`。

## 一、数据从哪里来、取哪一列

底稿是 Wind「基金比较」的导出，每只产品占 **10 列一组**，5 只产品横向并排：

| 组内位置 | 字段 | 是否使用 |
|---|---|---|
| 第 1 列 | 日期 | 否（用 Excel 日期序列号，在每组第 1 列，脚本读第 1 列） |
| 第 2 列 | 基金净值日期 | 否 |
| **第 3 列** | **复权单位净值(支持转型基金)** | **✅ 就是它，这是唯一的净值来源** |
| 第 4 列 | 基金净值更新频率 | 否（底稿里被净值数字覆盖了） |
| 第 5 列 | 复权单位净值 | 否（底稿中该列为空） |
| 第 6 列 | 复权因子 | 否（净值已复权，不需再乘） |
| 第 7、8 列 | 今年以来回报 / 单年度回报 | 否（预设窗口，与回测区间不符） |
| 第 9 列 | 回撤(相对前期高点) | 仅用于校验，单位是 **%**（-0.843 表示 -0.843%） |
| 第 10 列 | 基金组合久期 | 取不到（该列填的是日期序列） |

**为什么必须是复权净值**：如意65号区间内单位净值只涨 2.24%，复权后是 5.05%，差 2.8pp，全是分红。
用未复权净值算收益会系统性低估。

## 二、五个指标的定义

设第 t 日复权净值为 `P(t)`，区间内共 n 个交易日收益。

### 1. 区间收益

```
R = P(末) / P(初) - 1
```

### 2. 年化收益

```
年化 = (1 + R) ^ (365 / 实际自然日数) - 1
```

用自然日而非 252 个交易日折算，因为区间长度是 588 天，不是整数年。
本次：1.61 年，4.72% → 2.91%。

### 3. 年化波动率

```
r(t)   = P(t) / P(t-1) - 1          日收益率
σ_日   = 日收益率的样本标准差（分母 n-1）
年化波动 = σ_日 × √252
```

`√252` 就是"时间平方根法则"的放大倍数。**这一项最容易错**：
如果数据其实是周频而误用 252，波动率会被放大 √(252/52) ≈ 2.2 倍，夏普跟着腰斩。

### 4. 夏普比率

```
无风险日利率 rf = (1 + 1.0%)^(1/252) - 1
夏普 = (日均收益 - rf) × 252 / 年化波动
```

无风险利率取 **1.0% 年化**。这个参数必须写明，否则同一条曲线能算出 2.8 也能算出 2.5。

### 5. 最大回撤

```
peak = P(起点)
for 每个交易日 t:
    peak = max(peak, P(t))          # 更新历史最高点
    回撤(t) = P(t) / peak - 1
最大回撤 = min(回撤(t))
```

**回撤是路径依赖的非线性量**，这是它和收益、波动最关键的区别：
它不能由成分基金的加权平均得到，也不能由成分回撤的最大值估计——
组合回撤可能比所有成分都浅（本次组合1 的 -0.85% 就浅于青松单独的 -1.31%），
也可能更深，取决于各成分是否同时回撤。**只能逐日走一遍。**

### 6. 卡玛比率与索提诺（辅助）

```
卡玛   = 年化收益 / |最大回撤|
索提诺 = 年化超额收益 / 年化下行波动     下行波动只统计负偏离部分
```

## 三、组合怎么合成

**错误的做法**：把四只产品的净值先按权重加权平均，再算收益。
**正确的做法**：先按权重加总当日收益，再逐日复利。

```
组合日收益 R(t) = Σ wᵢ × rᵢ(t)          wᵢ 为权重，Σwᵢ = 1
组合净值   P(t) = P(t-1) × (1 + R(t))    P(0) = 1
```

权重：

| | 如意65号 | 创智 | 华泰 | 青松 | 稳盈（短债） | 现金 |
|---|---|---|---|---|---|---|
| 组合1 | 25% | 25% | 25% | 25% | — | — |
| 组合2 | 24% | 24% | 24% | 24% | 3% | 1% |

现金按 **0 收益**处理（不加息、不计货币基金收益），这是保守假设。

两者差别只在最后 4%：组合2 把 4% 从长债挪到短债和现金。

## 四、年度分段怎么切

老师要的"年度收益和年度回撤"与 Wind 的"年度回报"**不是一回事**：

| | 区间 | 说明 |
|---|---|---|
| Wind 单年度回报 | 2025-01-01 ~ 2025-12-31 | 完整自然年，含一季度 |
| 本文"2025" | **2025-04-01 ~ 2025-12-31** | 与回测起点对齐 |
| 本文"2026" | **2026-01-05 ~ 2026-11-09** | 年初第一个交易日 ~ 至今 |

两个分段首尾相接、不重不漏，`(1+2025段) × (1+2026段) = 1 + 全区间`，
可以直接验算。

**年度回撤**：在各自分段内独立找最高点、独立计算，所以 2025 段的回撤可以等于全区间回撤
（本次最深点 2025-09-25 正好落在 2025 段内），但 2026 段的回撤是独立重算的，会更浅。

## 五、校验方法（可以复现）

### 1. 与底稿回撤列比对

底稿第 9 列是 Wind 自己算的回撤（相对前期高点，单位 %）：

| 产品 | 底稿 | 自算 | |
|---|---|---|---|
| 如意65号 | -0.843% | -0.843% | 一致 |
| 创智国债增强 | -0.708% | -0.708% | 一致 |
| 华泰稳健增益 | **-1.988%** | **-0.691%** | 见下方说明 |
| 青松ESG1号 | -1.310% | -1.310% | 一致 |
| 稳盈专享3号 | -0.131% | -0.131% | 一致 |

四只完全一致。**华泰不一致是正常的**：Wind 那一列相对的是"全历史前期高点"，
华泰的高点在 2025-04-01 之前，所以它给的 -1.988% 里含了回测区间之外的下跌；
本文要的是"区间内最大回撤"，从区间首日开始找峰值，得到 -0.691%，这才是口径正确的数。

### 2. 与 PDF 区间收益比对

| 产品 | 本次（底稿，起于 4/1） | PDF（Wind，5.07 那栏） | 差 |
|---|---|---|---|
| 如意65号 | 5.06% | 5.07% | 0.01 |
| 创智国债增强 | 4.93% | 4.94% | 0.01 |
| 华泰稳健增益 | 4.17% | 4.17% | 0 |
| 青松ESG1号 | 4.74% | 4.75% | 0.01 |
| 稳盈专享3号 | 3.15% | 3.16% | 0.01 |

差 0.01pp 来自起始日取点。五只同时对得上，说明净值序列没抄错、口径没取错。

### 3. 分段乘积验算

```
(1 + 1.36%) × (1 + 3.29%) - 1 = 4.72%   ✓ 等于全区间收益
(1 + 1.35%) × (1 + 3.21%) - 1 = 4.63%   ✓
```

## 六、已知局限

1. **久期缺失**：底稿「基金组合久期」整列填的是日期序列，说明这 5 只保险资管产品
   不披露持仓明细，Wind 算不出基于利率风险的久期。报告里已写明缺失，未编造数字。
2. **现金按 0 收益**：若按货币基金约 1.3% 年化计，组合2 的收益会提高约 0.004pp，
   不影响任何结论。
3. **周频与日频的差别**：本脚本用日频。此前用周频取点时夏普 2.16、回撤 -0.80%；
   日频为 2.81、-0.85%。周频会同时**高估波动**（取点噪声）和**低估回撤**（漏掉盘中低点），
   所以交作业请用这一版日频结果。
4. **无风险利率敏感性**：RF 从 1.0% 调到 2.0%，夏普从 2.81 降到约 1.4。
   报告里必须写明 RF 取值，否则数字无法复核。
